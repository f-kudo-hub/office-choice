# note原稿の置き場所

ここにある `.txt` は、**noteにそのまま貼り付けられる形**の原稿です。
投稿はしません。最後のクリックは必ずご本人が行ってください。

---

## ⚠️ noteにA8のリンクは貼りません（2026-08-31 に決めたこと）

A8.net 側は note を媒体として認めていて、サイト登録も済ませました。
**ですが、note 側のルールはそうなっていません。**

- note の利用規約に「アフィリエイト禁止」の条文は**ありません**
- 一方で、**明確に許可されているのは Amazon アソシエイトだけ**です
  （noteはクリエイターのAmazonアフィリエイトIDを設定する仕組みを持っている）
- **A8などの外部ASPは、note公式のサポート対象外**という扱いです
- 実際に「アフィリエイト記事が公開できない」という報告が出ています

**つまり、A8を認めているのはA8であって、noteではありません。**
ここを混同すると、アカウントごと止まったときに集客の入口が丸ごと消えます。

### だからこうします

```
note の記事（A8リンクなし・自サイトへのリンクだけ）
        ↓
office-choice の該当ページ（ここにA8リンク。A8に登録済みの自サイトなので正規）
        ↓
提携先の窓口
```

**noteに貼るのは、自分のサイトへのリンクだけ。**これはどの規約でも問題になりません。

- 失うもの：1クリック挟むぶん、成約率は落ちます
- 得るもの：**アカウントが止まる可能性を踏まない**

止まったときの損失（集客の入口が消える）と、クリックが1つ増える損失は釣り合いません。
**片方は取り返せて、片方は取り返せません。**

副次的な効果もあります。noteからのリンクが office-choice に向くので、
いま一番足りていない**被リンクと流入**が、そのまま自サイトの土台になります。

## 貼るときの手順

1. note で「テキスト」の新規投稿を開く
2. このファイルの中身をそのまま貼る
3. 見出し（`■` で始まる行）を、noteの見出し（H2）に直す
4. **本文の最後にあるリンクが生きているか**を、投稿前に1つずつ押して確かめる
5. ハッシュタグは、原稿の末尾に書いてあるものを使う

**投稿はご本人が行ってください。**こちらは下書きまでです。
