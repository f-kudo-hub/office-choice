# 副業サイト（毎週1本、記事が自動で増えるアフィリエイトサイト）

毎週月曜の朝7時に、AIが記事を1本書いて、サイトに勝手に公開します。
PCの電源が入っていなくても、GitHubのサーバーが動かします。

---

## いちばん先に読んでいただきたいこと

この仕組みは**「記事が増えること」だけを自動にします。**
収入までは自動になりません。作る前に、この3つをご承知おきください。

**1. 検索に載るまで、ふつう半年ほどかかります。**
記事が増えても、すぐには誰も来ません。

**2. Amazonアソシエイトの審査は、通らないことがあります。**
登録から180日以内に3件以上の売上がないと失効します。
**まず記事を10本ほど溜めてから申請してください。**空のサイトで申請すると落ちます。

**3. Googleは「AIで量産しただけのサイト」を検索から外す方針です。**
2024年から明確にそうなりました。これが最大の落とし穴です。
この仕組みは、それを避けるために **AIに「実務でしか出てこない話を必ず1つ入れろ」** と指示していますが、
効くかどうかの保証はできません。**気になったら、月に一度でも記事を読んで手を入れてください。**
手が入った記事は、量産記事とは別物として扱われます。

## 最初の設定（1回だけ・15分ほど）

### ① Anthropic のAPIキーを作る

1. https://console.anthropic.com/ を開いてログイン
2. 左メニューの **API Keys** → **Create Key**
3. 出てきた文字列（`sk-ant-...`）をコピー。**この画面を閉じると二度と見られません。**

### ② GitHubで空のリポジトリを作る

1. https://github.com/new を開く
2. 名前を決める（例：`office-choice`）
3. **Public**（GitHub Pagesを無料で使うため）
4. **README も .gitignore も入れずに** 「Create repository」
5. 次の画面のURL（`https://github.com/…/office-choice.git`）をコピー

### ③ このフォルダを送り出す

**`はじめの設定.cmd` をダブルクリック**して、②のURLを貼るだけです。

会社の作業場の外（`C:\Users\あなた\副業サイト`）に中身をコピーしてから送ります。
**会社の台帳・記憶・secrets は一緒に出ていきません。**

### ④ GitHubの画面で、2つだけ設定する

送り終わると、画面に同じ案内が出ます。

**APIキーを預ける**
`Settings` → `Secrets and variables` → `Actions` → `New repository secret`
- 名前：`ANTHROPIC_API_KEY`
- 値：①でコピーしたキー

**サイトを公開する**
`Settings` → `Pages` → Source: `Deploy from a branch`
- Branch: `main` ／ フォルダ: `/docs` → `Save`

数分後、`https://あなたのID.github.io/office-choice/` が開きます。

### ⑤ 公開URLを設定に書く（検索に載るために必要）

`設定.json` の `"公開URL"` に、④で出たURLを貼って保存し、送り出してください。
これを入れて初めて `sitemap.xml`（検索エンジンへの目次）が作られます。

## 動かしてみる

**すぐ1本見たいとき**：`手で1本作ってみる.cmd` をダブルクリック。
手元で1本書いて、ブラウザで開きます。公開はしません。

**GitHub側で試すとき**：`Actions` タブ → `毎週の記事投稿` → `Run workflow`。

あとは毎週月曜の朝7時に、勝手に1本ずつ増えます。

---

## Amazonアソシエイトに登録できたら

`設定.json` の1行を書き換えるだけです。

```json
"Amazonトラッキングid": "あなたのID-22",
```

次の投稿から、**過去の記事もふくめて全ページ**にアフィリエイトリンクと
Amazon指定の表示文が入ります。1本ずつ直す必要はありません。

IDが空のあいだは、タグなしの検索リンクになり、「アフィリエイトです」とは表示しません。
**やっていないことを表示すると、それ自体が不当表示になるため**です。

## 中身の変え方

| 変えたいもの | 場所 |
| --- | --- |
| ジャンル・サイト名・読者像 | `設定.json` |
| 1回に作る本数 | `設定.json` の `1回に作る記事数` |
| 記事の書き方・禁止事項 | `tools/記事を作る.mjs` の「書きかたのルール」 |
| 見た目（色・文字） | `tools/サイトを組み立てる.mjs` の `CSS` |
| 投稿する曜日と時刻 | `.github/workflows/毎週の記事投稿.yml` の `cron` |

**ジャンルを変えたら、`記事/` の中身は消してください。**
古いジャンルの記事が残っていると、AIが「これ以外を書け」と受け取って、変な方向に伸びます。

## 表示のきまり（自動で入ります）

アフィリエイトは広告です。書き忘れると景品表示法（ステマ規制）に触れます。
そこで、AIの判断には任せず、**組み立てのときに機械的に**入れています。

- 全記事の本文が始まる前に「広告を含む」の1行
- 全ページの下に `disclosure.html`（広告と免責のページ）へのリンク
- Amazonリンクには `rel="nofollow sponsored"`
- 「この記事はAIが下書きしています」の但し書き

AIには「No.1」「最強」「絶対」を使わないよう指示していますが、
**指示は保証ではありません。**気になる表現を見つけたら、記事の元データ（`記事/*.json`）を直して
`手で1本作ってみる.cmd` ではなく `node tools/サイトを組み立てる.mjs` を実行すれば作り直せます。

## うまく動かないとき

**Actionsが赤くなる**
→ `Actions` タブ → 失敗した回 → 赤い行をクリックすると理由が出ます。
　いちばん多いのは `ANTHROPIC_API_KEY` の入れ忘れです。

**サイトが404**
→ `Settings` → `Pages` のフォルダが `/docs` になっているか確認してください。

**記事が増えない**
→ 定期実行は**既定ブランチ（main）でのみ**動きます。GitHubの仕様です。

**2か月以上さわらないと、GitHubが定期実行を止めることがあります。**
→ たまに `Run workflow` を手で押すか、リポジトリに何か1つコミットしてください。

## ファイルの中身

| 場所 | 役割 |
| --- | --- |
| `設定.json` | ジャンル・サイト名・Amazonタグ。**ふだん触るのはここだけ** |
| `記事/*.json` | 書けた記事の元データ。**これが資産です** |
| `docs/` | 公開されるページ。毎回まるごと作り直されるので、直接さわらない |
| `tools/記事を作る.mjs` | AIに記事を書かせる |
| `tools/サイトを組み立てる.mjs` | 記事データ → HTML |
| `.github/workflows/毎週の記事投稿.yml` | 毎週月曜7時の自動実行 |
| `はじめの設定.cmd` | 最初の1回だけ使う |
| `手で1本作ってみる.cmd` | 手元で1本試す |
