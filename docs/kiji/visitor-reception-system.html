無人化で減るのは「取次」であって「受付」ではない

来客受付システムは、受付に置いたタブレットで来客に訪問先を選んでもらい、担当者へ直接通知する仕組みです。導入でなくなるのは、電話を取って内線を回す取次の手間です。受付の仕事そのものが消えるわけではありません。

実際に残る仕事は次のようなものです。

  • 来客が来たときの案内（会議室がどこか、上履きが要るか）
  • 担当者が席にいないときの対応
  • 宅配便や業者の受け取り
  • 受付まわりの備品補充とタブレットの充電確認

兼任の総務が「受付担当を減らせます」と稟議に書くと、導入後に「結局変わっていない」と言われがちです。稟議に書くなら、減るのは取次の回数であること、そして取次が減ることで誰の手が空くのかを具体的に書くほうが通りやすくなります。

また、受付に人がいない前提になると、来客が迷ったときの逃げ道がなくなります。タブレットの操作がわからない来客、名前の読みが違う来客は一定数出ます。「困ったときはこの番号へ」という紙の掲示を一枚貼っておくかどうかを、導入と同時に決めてください。

契約前に決めるのは、呼び出し先と不在時の二段目

選定で最初に確かめるのは、呼び出しの方法です。製品によって、内線電話、ビジネスチャット、スマートフォンのアプリ、メールなど、対応している通知先が違います。自社がすでに使っている連絡手段に通知が飛ぶかどうかで、運用の定着がほぼ決まります。

確かめるのは次の点です。

  • 自社のチャットや内線と連携できるか。できない場合、担当者は何を見て気づくのか
  • 担当者が不在・会議中のときに、二段目として誰に飛ぶか（部署の共有チャンネル、総務、代表番号など）
  • 通知が誰にも気づかれなかったとき、来客側の画面に何が表示されるか
  • スマートフォンへの通知を使う場合、私物の端末を使うのか、会社の端末なのか

一番詰まるのは二段目です。担当者ひとりにしか飛ばない設定にしていると、その人が席を外した瞬間に来客が放置されます。部署の共有先へ自動で転送される設定があるか、何秒・何分で転送されるかは、契約前に確かめておく価値があります。

なお、私物スマートフォンに業務の通知を入れる場合は、通信費の扱いや退職時のアプリ削除をどうするかを、情報管理の規程側で決めておく必要があります。

タブレットとスタンドは誰の持ち物かを先に確かめる

来客受付システムは、ソフト（月額）と機器（タブレット・スタンド・プリンター）の組み合わせで成り立っています。この機器が「貸与」なのか「自社で用意」なのかで、費用も解約時の手間も変わります。

  • 貸与の場合：月額に機器代が含まれることが多い一方、解約時は返却が必要です。返却期限、送料の負担、破損時の弁償額を契約書で確かめます。
  • 自社調達の場合：タブレットとスタンドを自社で買います。初期費用は出ますが、解約しても端末は社内に残ります。対応OSのバージョン、画面サイズの下限が指定されていることがあるので、買う前に対応条件を確認します。

カタログに出てこない費用もあります。

  • 受付に電源がない場合の配線工事、または延長コードの処理（来客の足元を通す配線はつまずきの原因になります）
  • 受付のWi‑Fiが届かない場合のアクセスポイント追加
  • タブレットの盗難防止ワイヤーや、スタンドを床・壁に固定する工事
  • 入館証や来客シールを発行する場合のラベル用紙とインクの補充

特に見落とされやすいのがラベルの消耗品です。来客のたびに1枚печатаされる運用にすると、用紙代が毎月かかり続けます。発行をやめても運用が回るか、先に考えておくと無駄が減ります。

来客記録は個人情報。保存期間と閲覧できる人を決める

受付システムを入れると、来た人の氏名・会社名・訪問先・時刻が自動で記録に残ります。便利ですが、これは個人情報です。紙の受付簿と違い、まとめて検索・書き出しができる分、扱いは慎重にする必要があります。

契約前に決めておくのは次の点です。

  • 保存期間をどうするか。無期限にためるのか、一定期間で自動削除する設定があるのか
  • 管理画面を見られるのは誰か。全社員が見られる設定になっていないか
  • 来客データを書き出せるのは誰か。書き出したファイルをどこに置くか
  • 採用面接の来訪者をどう扱うか（誰が面接に来たかが社内に見えると問題になることがあります）

採用面接は現実によく揉めます。受付の画面で候補者が「人事部・採用面接」を選ぶと、通知先や記録を通じて社内に伝わります。候補者の氏名が社内で見える状態をよしとするか、面接だけ別の受付方法にするかは、人事と先に話を合わせておくべき点です。

また、来客記録は感染症の発生時や盗難時の確認に使われることがあります。「消す」と決めるなら、どのくらい残せば足りるかを総務・人事・情報管理の担当で一度合意しておくと、あとで慌てません。

宅配便・業者・常連の出入り ─ 想定外は受付で起きる

受付システムが想定しているのは「事前にアポがある来客」です。実際の受付には、それ以外の人のほうが多く来ます。ここを決めずに運用を始めると、タブレットの前で止まる人が出ます。

よくある例は次のとおりです。

  • 宅配便の配達員。訪問先を選べないので、押すボタンがありません。「配達の方はこちら」を一項目作るか、宅配ボックスや置き配の置き場所を掲示するかを決めます
  • 清掃・設備点検・自販機の補充など、定期的に来る業者。毎回受付を通すのか、鍵と入館の手順を別に決めるのか
  • 飛び込みの営業。受付システムでは担当者に直接つながるため、断る手間がかえって増えることがあります。「アポイントのない訪問はお受けしません」の掲示を先に用意しておくと楽になります
  • 来客の同行者が複数いる場合、全員分を入力してもらうのか、代表者だけでよいのか

あわせて、来客がどこで受付をするかも見ておきます。エントランスが共用部のビルでは、共用部にスタンドや掲示を置けるかどうかに管理会社の許可が要ることがあります。壁に貼る・床に固定するといった作業は、原状回復の対象になり得ます。契約の前に、ビルの管理規約と貸主への確認を一度挟んでください。

やめるときに詰まるのは、データ・返却・壁の穴

継続契約は、入るときより解約のときに手間が出ます。受付システムも同じです。契約前に、次の4点を見ておくと安全です。

  • 契約期間と解約予告。年単位の自動更新で、更新日の一定期間前までに申し出ないと次の1年が走る形が多く見られます。更新日を社内のカレンダーに登録しておきます
  • 初期費用の扱い。設定代行やキッティング（端末の初期設定）費用が、短期間で解約した場合に返金されないことがあります
  • 来客データの書き出し。解約後にアカウントが止まると、過去の来客記録が取り出せなくなる場合があります。CSVなどで書き出せるか、解約前に何日間の猶予があるかを確かめます
  • 機器の返却と撤去。貸与端末は返却、スタンドの固定やサインの貼り付けは撤去と原状回復が必要になることがあります

乗り換えを検討するときも同じです。新旧を並行して動かす期間を作れるか、来客に見える場所で切り替え作業ができるかを確かめます。受付は会社の第一印象が出る場所なので、半端な状態で放置すると社内から指摘が来ます。

最後に稟議の形です。「月額◯円で受付の取次がなくなります」ではなく、「取次がどのくらい発生しているか」「不在時に誰へ飛ばすか」「来客記録を何か月残して誰が見るか」「解約時に何が必要か」を一枚にまとめてください。まず1か月、受付への呼び出し回数と内容（来客・宅配・営業）を数えるところから始めると、判断の材料がそろいます。

買う前に確かめること

  • 自社のチャットや内線に通知が飛ぶか、不在時の二段目の転送先を設定できるか
  • 宅配便・定期業者・飛び込み営業の来訪時に、誰がどう対応するかを決めたか
  • 来客記録の保存期間と、管理画面を見られる人の範囲を社内で合意したか
  • タブレットとスタンドが貸与か自社調達か、解約時の返却・弁償条件を確認したか
  • 契約期間と解約予告の期限を、社内のカレンダーに登録したか
  • スタンドや掲示の設置について、ビル管理会社の許可と原状回復の範囲を確かめたか

よくある質問

受付に人を置くのとシステム、どちらが安く済みますか。

単純な金額比較はおすすめしません。受付専任者がいる会社では人件費との比較になりますが、総務が兼任で取次している会社では、削減されるのは金額ではなく中断の回数です。まず1か月、受付対応が1日に何回発生し、そのうち何回が来客・宅配・営業かを数えると、稟議で使える材料になります。

来客の記録は、どのくらい残しておけばよいですか。

法律で一律の保存期間が決まっているわけではないため、自社で決める必要があります。盗難や感染症の発生時にさかのぼる可能性を踏まえて期間を決め、過ぎたものは自動で消える設定があるかを確認してください。無期限にためると、閲覧権限と退職者のアカウント整理の管理が重くなります。

タブレットは会社で買うのと、貸与を受けるのとどちらがよいですか。

解約の可能性をどう見るかで変わります。貸与は初期費用を抑えやすい一方、解約時に返却と破損時の弁償が発生します。自社調達は初期費用が出ますが端末が残るため、将来の乗り換えや別用途への転用がしやすくなります。対応OSのバージョン指定があることが多いので、購入前に必ず条件を確認してください。

社内から「人が出迎えないのは失礼だ」と反対が出ます。

全来客を一律に無人化しない運用で折り合えることがあります。重要な来客は担当者が事前にエントランスで待つ、通常の打ち合わせはシステム経由にする、といった線引きを先に決めておく方法です。反対の理由が「印象」なのか「来客が迷わないか」なのかを切り分けると、掲示の工夫で解決する場合もあります。
