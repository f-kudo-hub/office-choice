止まるのはホームページではなく、会社のメールです

ドメイン（example.co.jp のような会社の住所にあたる文字列）が失効すると、まず気づかれるのはホームページが見えなくなることです。しかし業務への打撃が大きいのは、その裏で会社のメールが送受信できなくなることです。多くの会社は、ホームページと同じドメインでメールアドレスを作っています。ドメインが失効すれば、請求書の送付も、取引先からの問い合わせも、採用応募の受信も同時に止まります。

さらに厄介なのは、失効の影響がすぐには元に戻らない点です。失効後に再登録できる猶予期間はレジストラ（ドメインを登録・管理する事業者）や種類によって異なり、猶予を過ぎると第三者が取得できる状態になることもあります。復旧にかかる手数料も通常の更新料より高く設定されている場合があります。

  • ドメインは「毎年払う会社の看板と郵便受け」だと考える
  • 止まると困るのはサイトよりメール、と社内に説明する
  • 年に一度の更新日を、総務の年間予定表に載せる

ここを押さえておくと、次の「名義」の話が単なる事務手続きではないと伝わります。

名義が個人や制作会社のまま、はよくあります

確かめる順番は決まっています。まずドメインの登録者名義、次に更新通知の届く先、最後に支払方法です。

よくあるのは、創業期に社長や当時の担当者が個人名義・個人のメールアドレスで取得し、そのままになっているケースです。ホームページを作った制作会社が、自社名義でまとめて管理していることもあります。どちらも普段は困りませんが、退職や取引終了のときに一気に詰まります。名義人本人でないと管理画面に入れない、移管に必要な情報を出してもらえない、連絡が取れない、といった形です。

  • 登録者名義は法人名か、個人名か
  • 管理画面のIDとパスワードを社内の誰が持っているか
  • 更新通知メールの宛先は、退職しても消えないアドレスか
  • 支払いは法人カードか、口座振替か、個人のカードか

個人のクレジットカードで自動更新していると、その人が辞めてカードを解約した時点で更新が止まります。総務が気づくのは、たいていメールが届かなくなってからです。

サーバー契約は、解約した瞬間にデータが消えます

レンタルサーバー（ホームページやメールの置き場所を借りる契約）は、月額や年額が安い分、解約の扱いがあっさりしています。解約日を過ぎるとサーバー上のデータが削除され、そこに保存されていたメールも一緒に消えることがあります。バックアップの保持期間や、解約後にデータを取り出せるかどうかは事業者によって違います。

乗り換えを検討するときは、金額より先にこの三つを確かめてください。

  • 解約後、データがいつまで残るか。取り出しに追加費用がかかるか
  • メールの過去データを新しいサーバーへ移す作業は誰がやるか
  • 移行中にメールが受信できない時間が発生するか、その長さの見込み

メールの移行は、端末に残っている分と、サーバーに残っている分で扱いが変わります。社員が各自のパソコンで管理している場合、会社側でまとめて移せないこともあります。移行日を決める前に、社員へ「この日までに必要なメールを保存してください」と周知する段取りが要ります。

工事や機器の話がない分、油断されやすい契約です。

制作会社の保守契約は、どこまで含むかを書面で確かめる

ホームページを外部に作ってもらった会社では、月額の保守契約がついていることがあります。契約書を見ると「サーバー・ドメインの管理」と一行だけ書かれている場合が多く、その中身が曖昧なままになりがちです。

確かめるのは次の点です。

  • ドメインとサーバーの契約者は自社か、制作会社か（自社名義なら、保守を切っても残せます）
  • 保守料に、更新料と利用料が含まれているか。別請求か
  • SSL証明書（通信を暗号化する仕組み）の更新は誰の担当か
  • 契約終了時に、管理画面の情報とサイトのデータを引き渡す取り決めがあるか
  • 引き渡し作業に費用が発生するか

契約終了時の引き渡しについて何も書かれていない契約は珍しくありません。揉めるのは料金ではなく、この引き渡しのところです。更新のタイミングで一文を追加してもらうだけでも、状況は変わります。無理に名義を取り戻す必要はありませんが、少なくとも「いつ、何を、いくらで渡してもらえるか」は紙にしておきます。

退職の前後で、総務がやる手続きの順番

担当者の退職が決まってからでは遅いこともあります。通常の引き継ぎ書には、ドメインやサーバーの項目が入っていないためです。

  • 退職が決まったら、その人名義・その人のアドレスで登録している外部契約を洗い出す
  • ドメインの登録者情報を、法人名と部署宛アドレスへ変更する
  • 更新通知の宛先を、個人ではなく総務の共有アドレスに変える
  • 支払方法を法人カードまたは口座振替に切り替える
  • 管理画面のIDとパスワードを、法人向けのパスワード管理の仕組みに登録する

名義変更（登録者情報の変更）と移管（別の事業者へ移すこと）は別の手続きです。移管には認証用のコードが必要だったり、直前に移管したばかりのドメインは一定期間動かせなかったりと、事業者ごとに条件があります。退職日の直前に駆け込むと間に合わないことがあるので、余裕をもって着手してください。

引き継ぎ書に「ドメイン・サーバー」という行を足す。まずはそこからで構いません。

稟議は金額ではなく、止まったときの影響で書く

年間で数万円程度の話なので、稟議書に金額だけ書くと「そんなものか」で終わり、優先順位が下がります。通したいのは支出の承認ではなく、名義と管理の整理です。

稟議には次の順で書くと、判断する側に伝わります。

  • 現状：ドメインの名義が誰か、更新通知がどこへ届いているか
  • 想定される事態：更新切れでメールが送受信できなくなる。復旧に時間と追加費用がかかる可能性がある
  • 対応：名義を法人へ、通知先を共有アドレスへ、支払いを法人契約へ
  • 費用：更新料のほか、名義変更や移管にかかる手数料の見込み
  • 担当：誰が管理台帳を持ち、誰が更新日を確認するか

台帳は表計算ソフト一枚で十分です。ドメイン名、登録事業者、契約者名義、更新日、支払方法、管理画面の所在、関係する取引先。これを作って年に一度見直すだけで、退職のたびに探し回る状態からは抜けられます。まずは自社のドメインが誰の名前で登録されているか、今日確認してみてください。

買う前に確かめること

  • ドメインの登録者名義が法人名になっているか確認する
  • 更新通知の宛先が退職しても残るアドレスか確認する
  • 支払方法が個人カードになっていないか確認する
  • サーバー解約後にデータが何日残るかを事業者に聞く
  • 保守契約に更新料と引き渡しの取り決めが含まれるか確認する
  • ドメイン・サーバーの管理台帳を作り更新日を記入する

よくある質問

ドメインの名義が退職した社員の個人名のままです。今からでも変えられますか。

多くの場合、登録者情報の変更手続きで法人名義へ切り替えられます。ただし管理画面へのログイン情報や、本人確認の連絡が必要になることがあります。連絡が取れるうちに着手したほうが手間が少なく済みます。

制作会社の名義になっています。自社に移すべきでしょうか。

取引が続いている間は、すぐに移さなくても実務上は回ります。重要なのは、契約終了時に管理情報とデータを引き渡す取り決めを書面に残しておくことです。移管を希望する場合は、手続きと費用を事前に確認してください。

更新切れを防ぐ一番簡単な方法は何ですか。

更新通知の宛先を個人ではなく総務の共有アドレスにし、支払いを法人カードか口座振替にすることです。加えて、更新日を年間予定表に書き込んでおくと、自動更新が失敗した場合にも気づけます。

サーバーを移すとメールは止まりますか。

切り替えの作業中に、一時的に送受信できない時間が生じることがあります。長さは構成や事業者によって異なるため、事前に見込みを聞いてください。過去のメールを移す作業も別途必要になる場合があります。
