最初に決めるのは価格ではなく「対象者の範囲」

見積もりを取る前に、社内で対象者を確定させてください。ここが曖昧なまま単価だけ比べると、後から人数が増えて予算が合わなくなります。

労働安全衛生法では、常時使用する労働者に対しておおむね年1回以上の定期健康診断が事業者に義務づけられています。深夜業などの特定業務に従事する人は、年2回程度など頻度が変わる扱いがあります。新しく雇い入れるときの健診も別枠です。自社にどれが当てはまるかは、所轄の労働基準監督署や厚生労働省の資料で最新の内容を確かめるのが確実です。

迷いやすいのが次の人たちです。

  • パート、アルバイト（所定労働時間が通常の労働者と比べて一定割合以上かどうかで扱いが変わります）
  • 契約社員、嘱託、再雇用の人
  • 役員（労働者かどうかで整理が分かれます）
  • 育休中、休職中の人
  • 在宅勤務が中心で出社頻度が低い人

「対象者は何人、そのうち特定業務は何人、年度内のいつ受けるか」。この3つが決まっていれば、どの委託先に聞いても比較できる見積もりが返ってきます。逆にここが決まっていないと、見積もりの前提がばらばらになり、稟議で「なぜこの会社なのか」を説明できなくなります。

巡回健診と医療機関での個別受診、向き不向きは人数と拠点数で決まる

健診の受け方は大きく2つです。どちらが安いかではなく、自社の働き方に合うかで選びます。

巡回健診は、健診車や設備が会社に来て、その日にまとめて受ける方式です。移動時間がなく、受診率を上げやすいのが利点です。一方で、駐車スペースや電源、更衣と待機のための部屋が要ります。ビルの共用駐車場が使えるか、管理会社の許可がいるかは早めに確認が必要です。最低実施人数が設定されていることも多く、少人数だと割高になるか、そもそも受けてもらえません。

個別受診は、社員が指定の医療機関に予約して各自で受ける方式です。拠点が分かれている会社や、在宅勤務が多い会社に向きます。ただし予約は本人任せになりやすく、受診が後ろ倒しになりがちです。医療機関ごとに費用や請求のしかたが違い、総務が立替精算を処理する手間も増えます。

健診の手配をまとめて請け負う代行サービスもあります。全国の医療機関の予約、受診券の発行、請求の一本化までを引き受ける形です。拠点が散っている会社では事務負担が下がりますが、代行手数料が一人あたりで乗るので、少人数だと効果が出にくいことがあります。

見積もりに出ていない費用が、あとから請求書に乗る

健診の見積もりは「法定項目一式でいくら」と書かれていることが多く、ここに含まれない費用が後から出てきます。契約前に、次のどれが別料金かを書面で確認してください。

  • オプション項目（がん検診、婦人科検診、追加の血液検査など）を会社が一部負担する場合の精算方法
  • 年齢や条件で会社が補助する項目の線引き
  • 当日欠席、直前キャンセルのキャンセル料
  • 再検査、精密検査の費用（原則は本人負担とする会社が多いものの、社内規程で決めておかないと都度もめます）
  • 結果データを電子ファイルで受け取る場合のデータ化費用
  • 巡回健診の出張費、最低人数に満たないときの追加料金
  • 産業医や医師による就業判定を依頼する場合の費用

とくにオプションの扱いは、社内の不満が出やすいところです。「去年は会社が出してくれた」と言われないよう、会社負担の範囲を文書にして案内に載せます。

もう一つ、請求の締め日にも注意してください。年度末に駆け込みで受診した分の請求が翌期に回ると、予算の年度がずれます。経理と、どの時点の受診分をどの期で処理するかを先にすり合わせておくと、決算前に慌てずに済みます。

予約枠は先に埋まる ─ 年間スケジュールと未受診者の督促

健診は、春と秋に申し込みが集中しやすい時期があります。希望日を決めるのが遅れると、巡回健診の日程が押さえられなかったり、個別受診でも近隣の医療機関が埋まっていたりします。実施したい時期のかなり前に問い合わせる前提で動くのが安全です。

運用で必ず詰まるのが未受診者です。案内を一斉送信して終わりにすると、繁忙部署や外回りの人が残ります。効く手は地味な仕組み化です。

  • 受診期限を「年度末」ではなく、余裕を持った日に設定する
  • 受診状況の一覧を月1回、部門長に共有する（個人の結果は渡しません。受けたかどうかだけです）
  • 未受診者には期限前に個別連絡し、予約日を返信してもらう
  • 健診の受診にかかる時間の扱い（就業時間内か、賃金を払うか）を先に決めて案内に明記する

受診時間の扱いは質問が集中する点です。一般の定期健康診断は業務との関連が薄いため労働時間として扱う義務まではないとされる一方、円滑に受けてもらう観点から就業時間内扱いにする会社も多くあります。どちらにするかを決めて、案内文に書いてください。曖昧なままだと、部署ごとに運用が割れます。

結果の受け取り方と保管 ─ ここが総務のいちばんの負担

健診が終わってからが総務の本番です。結果は機微な個人情報です。取り扱いを決めずに始めると、後で整理がつかなくなります。

確かめるのは次の点です。

  • 結果はいつ届くか（受診からおおむね数週間かかることが多く、年度末受診だと報告が間に合わないことがあります）
  • 本人あての結果と、会社あての控えが別々に届くか、封をした状態か
  • 会社が受け取るのは紙かデータか。データなら形式と受け渡し方法（パスワード付きか、専用の画面からの取得か）
  • 閲覧できるのを誰に限るか。鍵のかかる場所か、アクセス権を絞ったフォルダか

健診の記録は、法令でおおむね5年の保存が求められています。紙で受け取ると、年々ファイルが増え、保管場所を圧迫します。電子で受け取れるなら、その分の費用と手間を最初に比べておくと後が楽です。

また、常時50人以上の労働者がいる事業場では、定期健康診断結果報告書を所轄の労働基準監督署に提出する必要があるとされています。人数が増えて基準をまたぐ年は、報告の要否を必ず確認してください。有所見者への対応（医師の意見聴取や就業上の措置）も事業者の義務とされる部分があり、産業医の契約とセットで考える話になります。

委託先を替えるとき、引き継げないのは過去の結果データ

継続契約は、入るときより替えるときに詰まります。健診も同じです。

健診機関を替えると、過去の受診結果は前の機関に残ります。多くの場合、そのまま新しい機関に移せるわけではありません。経年で数値の変化を見たい場合、会社側に控えが残っていなければ比較できなくなります。だからこそ、会社が受け取る控えを毎年きちんと保管しているかが効いてきます。切り替えを検討する前に、手元に何年分あるかを確かめてください。

契約面では、次を書面で確認します。

  • 契約期間と自動更新の有無、解約の申し出はいつまでか
  • 年間の最低実施人数や最低金額の設定があるか
  • 予約済み日程をキャンセルする場合の費用
  • 保管されている自社の受診データについて、解約後の扱い（返却、削除、保存期間）

最後の項目は忘れられがちですが、個人情報を預けている以上、解約後にどうなるかを聞いておく価値があります。「削除の報告をもらえるか」まで確認できれば十分です。

替える理由が「単価が少し安いから」だけなら、切り替えの事務負担と釣り合わないこともあります。受診率が上がらない、日程が取れない、結果が遅いといった運用上の困りごとが理由なら、替える意味があります。

稟議の通し方 ─ 単価ではなく「義務と手間」で説明する

健診の稟議は、金額の話だけだと「去年と同じでいいのでは」で止まりがちです。通しやすいのは、次の3点を並べる書き方です。

1つめは、法令上の義務であること。事業者に実施義務があり、常時50人以上の事業場では労基署への報告も必要とされます。未実施は会社のリスクです。「やるかどうか」ではなく「どうやるか」の決裁だと位置づけます。

2つめは、受診率です。前年の受診率と未受診者数、督促にかかった総務の時間を書きます。巡回健診への変更や代行サービスの利用を提案するなら、単価が上がっても未受診が減る見込みを根拠にします。数字は自社で数えられるものだけ使ってください。

3つめは、年間の総額です。一人あたりの単価だけでなく、オプション会社負担分、キャンセル料の想定、データ化費用まで含めた見込み額を出します。前年の実績請求額と並べると、経営層が判断しやすくなります。

進め方はこの順です。対象者を確定する → 実施方式（巡回か個別か代行か）を2案に絞る → 別料金の項目を書面でもらう → 日程を仮押さえする → 稟議 → 社内案内と期限設定。日程の仮押さえを稟議の後に回すと、希望の時期が埋まります。仮押さえの条件（いつまでならキャンセル料なしか）を聞いたうえで、先に枠を確保しておくのが現実的です。

買う前に確かめること

  • 対象者の範囲（パート・役員・休職者）を人数まで確定させたか
  • 法定項目以外で別料金になる項目を、書面で一覧にしてもらったか
  • 当日キャンセル料と、日程の仮押さえをいつまで無料で保持できるかを確認したか
  • 結果の受け取り方法（紙かデータか）と、社内で閲覧できる人の範囲を決めたか
  • 常時50人以上の事業場に該当する年か、労基署への報告要否を確認したか
  • 解約時に、預けている受診データがどう扱われるかを聞いたか

よくある質問

パートやアルバイトも定期健康診断の対象になりますか。

契約期間や所定労働時間が一定の基準を満たす場合、対象になるとされています。基準の線引きは細かいため、自社の雇用形態ごとに所轄の労働基準監督署や社労士に確認するのが確実です。対象外の人にも会社の判断で受けてもらう運用は可能ですが、その場合は費用負担の扱いを先に決めてください。

健診を受ける時間は労働時間として扱う必要がありますか。

一般の定期健康診断については、労働時間として扱う義務まではないとされる一方で、円滑な受診のために就業時間内扱いとする会社も多くあります。業務に起因する特殊健診は扱いが異なります。どちらにするかを決めて、社内案内に明記しておくと運用が割れません。

オプション検査の費用は会社が出すべきですか。

法令で義務づけられた項目以外は、会社が負担する義務はないのが原則です。ただし福利厚生として一部を補助する会社もあります。補助するなら対象項目と上限額を規程に書き、毎年の案内に同じ文言を載せてください。前年と扱いが変わると不満が出やすい部分です。

年度末に受診した人の結果が間に合いません。どうすればよいですか。

結果の到着には受診からおおむね数週間かかることが多く、期限ぎりぎりの受診は報告や事後措置に響きます。受診期限を年度末より前に設定し、未受診者への連絡をその手前で行う運用にしておくと詰まりにくくなります。委託先には、結果到着までの目安日数を事前に確認しておいてください。
