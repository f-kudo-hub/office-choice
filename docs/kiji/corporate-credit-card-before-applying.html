法人クレジットカードの申し込み、総務が決める前に確かめる限度額と退職時の回収

この記事で紹介しているのは、申し込む形のサービスです。現在、アフィリエイトの提携はありません。

法人クレジットカードは、年会費とポイント還元率だけで比べると、あとで困ります。実際に総務の手間が増えるのは、月末に限度額が足りずに決済が止まったときと、社員が辞めてカードを回収しそびれたときです。この記事を読むと、何枚どう持たせるか、限度額をいくらで申請するか、やめるとき（カード会社を変えるとき）に何が起きるかが、申し込み前に決まります。稟議で聞かれる「今と比べて何がよくなるのか」の材料もあわせて整理します。

最初に決めるのは枚数ではなく「誰に、何を払わせるか」

法人カードを検討する理由は、たいてい「社員の立替払いをやめたい」「サブスクの支払いを個人カードから会社名義に移したい」のどちらかです。ここを混ぜたまま申し込むと、あとで枚数と限度額の設計が崩れます。

先に紙に分けて書くのが早道です。

  • 会社として固定で払うもの（クラウドサービス、広告費、通信費、ドメイン、サーバー）
  • 出先で人が使うもの（出張の交通費・宿泊、接待、備品の緊急購入）
  • 特定部署だけが使うもの（採用広告、仕入れ）

固定の支払いは、人に紐づけず「経理部が保管する1枚」に集約するのが管理しやすい形です。担当者が異動しても支払いが止まりません。逆に出張が多い人には個人名義の追加カード（社員名が刻印された子カード）を持たせたほうが、精算が減ります。

よくあるのは、部長職だから、という理由だけで全員に配ってしまうケースです。使われないカードにも年会費がかかり、退職のたびに回収が発生します。使う人にだけ配る、を最初の原則にしておくと後が楽です。

限度額で詰まる ─ 月末に決済が止まらない枠の考え方

法人カードでいちばん多いつまずきは、限度額（利用枠）の不足です。年会費の安いカードは枠が小さめに設定されることがあり、申し込み時の希望額がそのまま通るとも限りません。

確かめるのは次の点です。

  • 枠は会社全体で共有か、追加カードごとに個別設定できるか
  • 締め日と引き落とし日、その間の枠の復活タイミング
  • 一時増枠（スポットで枠を上げる手続き）の可否と、申請から反映までの目安日数

枠は「月の平均利用額」ではなく「いちばん多い月」で考えます。決算期の広告出稿、展示会、まとめ買い、出張が重なる月です。しかも、支払い済みの金額が枠に戻るのは引き落とし後なので、締め日直後にまとめて使うと、月末に枠が残っていない状態が起きます。

枠が足りずに決済が通らないと、結局その場で社員が個人カードを出すことになり、立替をなくすという目的が達成できません。設立から日が浅い会社や、直近が赤字の会社は審査で枠が絞られやすいため、あらかじめ複数の選択肢を持っておくほうが安全です。

年会費・ポイント・保険は「誰のものか」を先に決める

年会費は、無料のものから数万円程度まで幅があります。追加カードは1枚ごとに年会費がかかる場合と、数枚まで無料の場合があるので、枚数を掛け算して年間コストを出してください。10枚配れば、年会費の差が思ったより効いてきます。

もめやすいのがポイントとマイルです。会社の経費で貯まったポイントを、カードを持っている個人が私用に使える状態にしておくと、社内で不公平感が出ます。

  • ポイントは会社に帰属する、と規程に一行書く
  • 貯めたポイントの使い道（支払い充当、備品購入）を決めておく
  • 充当した分をどう会計処理するか、税理士に先に聞いておく

付帯保険も同様です。海外出張の旅行傷害保険が付くカードは多いですが、「利用付帯」（そのカードで旅費を払ったときだけ有効）か「自動付帯」かで、実際に使えるかが変わります。既に加入している出張者向けの保険と補償が重なっていないかも、あわせて見ておくと無駄が減ります。

明細の取り込みと証憑の保存 ─ 経理の手間はここで決まる

カードを入れると立替精算は減りますが、経理の仕事がゼロになるわけではありません。むしろ「これは何の支払いか」を後から特定する作業が増えることがあります。

申し込み前に確かめるのは次の点です。

  • 利用明細をCSVなどで落とせるか、会計ソフトや経費精算サービスと連携できるか
  • カード会社のサイトで明細を見られる期間（一定期間を過ぎると閲覧できなくなることがあります）
  • 追加カードごとに利用者名が明細に出るか

明細の保存期間には注意が必要です。過去分をいつでも見られると思っていると、税務調査や監査のときに出せない、ということが起こります。毎月決まった日にダウンロードして保存する担当を決めておくのが現実的です。

もう一点、カードの利用明細は領収書の代わりにはならない場面があります。電子帳簿保存法では、ネットで受け取った領収書やレシートのデータはデータのまま保存する扱いになります（電子取引データ保存）。カードで払ったから紙は不要、と運用を切り替える前に、何を残すかを税理士と決めてください。ここを曖昧にしたまま配ると、あとで全員に「あの月のレシートを出して」と頼む羽目になります。

やめるとき・辞めるときに詰まる ─ 回収とサブスクの付け替え

継続契約は、入るときより終わるときに手間がかかります。法人カードも同じです。

社員が退職するとき。追加カードの回収を忘れると、カードは生きたままです。しかも、そのカードに毎月のクラウドサービス代を紐づけていると、無効化した瞬間に決済が失敗し、サービスが止まります。退職手続きのチェックリストに「カード回収」と「そのカードに紐づく定期支払いの洗い出し」を並べて入れておくと、片方だけ忘れる事故が減ります。

カード会社を乗り換えるときは、もっと大変です。会社で使っているクラウドサービス、広告アカウント、ドメイン、通販サイトの支払い情報を、ひとつずつ管理画面で入れ替える必要があります。カード会社側でまとめて付け替える仕組みは基本的にありません。

  • 支払い先の一覧（サービス名・金額・支払い月・管理者）を先に作る
  • 誰のアカウントで契約しているか不明なものを洗い出す
  • 旧カードは、切り替え後1〜2か月ほど残高と請求を見てから解約する

この一覧は、退職時にも、乗り換え時にも、そのまま使えます。カードを申し込む前に作っておくと、あとの作業が一度で済みます。

稟議の通し方と、配る前に決めておく運用ルール

稟議で「年会費が増える」とだけ見られると止まります。比べるべきは、今かかっている見えないコストです。

  • 立替精算の振込手数料（人数×月の回数）
  • 精算書の作成と承認にかかる時間
  • 社員が自腹で立て替えている状態への不満（採用や定着にも効きます）
  • 支払いが個人カードに紐づいたままのサービスが止まるリスク

これを並べると、金額の話から運用リスクの話に変わり、判断しやすくなります。

配る前には、A4一枚で運用ルールを作ってください。書くのは、使ってよい費目とだめな費目、1回あたりの上限、領収書の提出期限と方法、私的利用が判明したときの扱い、紛失時の連絡先と手順、退職時の返却義務です。これを受領書と一緒に署名してもらってから渡します。

まとめると、順番はこうです。支払いの一覧を作る → 誰に持たせるかを決める → いちばん多い月から限度額を逆算する → 明細と領収書の保存方法を税理士と決める → 運用ルールを作る → 申し込む。この順で進めれば、限度額不足と回収漏れという二大つまずきは、かなり避けられます。

買う前に確かめること

  • いちばん利用額が多い月を基準に、必要な限度額を計算したか
  • 追加カードの年会費を、配る枚数分まで掛け算して年額で出したか
  • そのカードに紐づける定期支払いの一覧（サービス名・金額・管理者）を作ったか
  • 退職手続きのチェックリストに、カード回収と支払いの付け替えを入れたか
  • 明細のダウンロード期限と、領収書をどう保存するかを税理士と決めたか
  • ポイントとマイルが会社に帰属することを、規程か通達で明文化したか

よくある質問

設立して間もない会社や、直近が赤字でも法人カードは作れますか。

作れる場合もありますが、限度額が希望より小さく設定されることがあります。決算書の提出を求められないタイプや、預けた金額の範囲で使うデポジット型・プリペイド型なら通りやすい傾向があります。まず1枚作って実績を積み、あとから増枠や別カードを検討する進め方が現実的です。

社員の個人カードで立て替えてもらう方式と、どちらが得ですか。

金額だけなら立替のほうが安く見えますが、振込手数料と精算作業の時間、社員の負担感が乗ってきます。とくに数万円単位の出張費を毎月立て替えさせる状態は、不満が出やすい部分です。固定のサブスク支払いだけでも会社名義に移すと、担当者の退職時に支払いが止まるリスクを減らせます。

代表者の個人保証や個人与信は必要ですか。

カードの種類によって扱いが分かれます。代表者個人の信用情報を見るもの、法人の決算内容を見るもの、どちらも見るものがあります。申込書に何を書かせるかで見当がつきますが、気になる場合は申し込み前にカード会社へ直接確認してください。

カードを紛失したとき、総務は何をすればよいですか。

まず本人にカード会社の紛失受付へ連絡させ、そのカードを止めます。そのうえで、そのカード番号に紐づけている定期支払いがないかを確認してください。再発行は数日から数週間かかることがあるため、出張予定がある場合は代替の支払い手段を先に用意しておくと慌てずに済みます。
